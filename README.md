## Overview

D16 Group Toraverb is a high-quality algorithmic reverb with an unusual approach to decay shaping, offering separate high and low frequency decay times for precise acoustic space design.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group Toraverb** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Decay** | Independent high-frequency and low-frequency RT60 decay times |
| **Pre-Delay** | Up to 200 ms pre-delay with tempo sync for rhythmic early reflections |
| **Density** | Adjustable echo density and diffusion for small to large spaces |
| **Color Controls** | Vintage tilt EQ on the reverb tail for warm or bright character |
